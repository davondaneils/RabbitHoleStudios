## Applying the library
First write the audience promise and complete causal outline. Draft connected narration. Then conduct a separate skeptical edit with exact troublesome passages and repairs. Do not decorate the script with every available technique. If a clever line conflicts with immediate understanding, rewrite it plainly.

Before presenting a candidate, ask: could a distracted first-time listener tell what happened and why, without rereading? Text review is preliminary evidence only. Actual spoken delivery, visual execution and human approval must be reported separately.
