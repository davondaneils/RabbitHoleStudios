## Working doctrine

**Research expansively. Create selectively. Edit ruthlessly.** The studio rules are a tool palette, not a 50-item writing prompt. Each episode needs one clear promise, a lived-in human world, a satisfying payoff, and economical production. No lore, products, software automations or recurring memberships until the market earns them.

## Update protocol

At the end of a studio sprint, change only: `README.md` (current next action), `TRACKING/pilots.csv`, and `STUDIO/decisions.md` if a real decision changed. Update a Show Bible or Creative OS only when a repeatable lesson was learned. Avoid documentation for its own sake.
