- Right to use source images or footage is not established. Draw **original character and UI reenactments**, never present simulated 2017 TripAdvisor visuals as authentic archival evidence. Use no original dialogue/voice clips without rights and ethical review.
- The script mentions an invented waiting list as a **stated six-week unavailability**, not real bookings. Note this in graphics.
- Storytelling review remains a founder gate; quality and length cannot be “unit tested” from a source audit alone.
- Reference status for Oobah's character is **candidate**, not approved; no animation work authorized by this commit.
